# nikke-hub (이전 주소)

NIKKE Hub는 **NIKKE Portal** 로 이름과 주소가 바뀌었습니다.

- 새 주소: https://ssissun.github.io/nikke-portal/
- 새 repo: https://github.com/ssissun/nikke-portal

이 repo는 예전 주소 https://ssissun.github.io/nikke-hub/ 로 들어온 사람을 새 주소로 보내기 위해서만 남겨 둡니다.

- `index.html`, `404.html`: 경로·쿼리·`#해시`를 유지한 채 새 주소로 이동
- `nikke-hub-sync.user.js`: 예전 주소로 설치한 사용자 스크립트를 새 주소(`nikke-portal-sync.user.js`)로 넘기는 다리. 한 번 받으면 그 뒤로는 새 주소에서 업데이트되므로 이 파일은 더 고치지 않음 (스크립트 수정은 nikke-portal 쪽에서만)
